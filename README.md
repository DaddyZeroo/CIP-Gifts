# CIP Gifts

A web application for presenting and managing CIP rewards and gifts.

## Overview

This project contains the web interface for the CIP Gifts experience, with the frontend source organized under `premios-cip`.

## Live demo

[Open CIP Gifts](https://cip-gifts.vercel.app)

## Repository contents

- `premios-cip`: web application source

## Getting started

Open the `premios-cip` directory and follow the project instructions there. The deployed version is available through the live demo link above.
